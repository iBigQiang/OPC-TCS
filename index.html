推文卡片生成器（OPC Tweet Card Studio）

把推文做成可直接发布的图片卡片：写文案或导入你的推文库 → 选背景 → 导出 3:4 / 9:16 竖图、透明 PNG，或 3 秒动效 Live 图素材（MP4）。卡片在浏览器本地生成，设置仅存本机浏览器；在线抓取按需发送请求。

也可以让 AI Agent 直接调用：调好样式后到左下角「交给 AI Agent」复制一段指令，发给 Claude Code / Codex 即可批量出图（参数文档）。

01

选择内容

从推文库选一条，或自己写

02

推文库

搜索推文，点击上卡

选择 JSON 文件，替换本机推文库。已有内容需要保留时，请先导出备份。

推文库格式：JSON 数组，每条只有 text 必填；date / datetime / topic / sourceUrl / metrics / media 可选。互动数据沿用新接口字段，真实的 0 会保留，仅缺少互动数据时随机填充。

将当前本机推文库完整下载为 JSON 文件，可用来备份或导入其他浏览器。

清除本机推文库和同步记录，重新载入站点默认推文库。请先导出需要保留的内容；账号信息和接口设置会保留。

导入的数据只保存在当前浏览器；导出仅下载到你的设备。这些操作不会上传数据或修改线上推文库。

    02

    在线抓取

    贴一条推文链接，直接抓成卡片

    支持 API 根域名（如 https://x-api.opc.tools）或完整接口地址，根域名会自动补全 /import/twitter。

    接口地址、访问令牌和账号信息仅保存在本机浏览器，保存设置本身不发送请求。抓取时，令牌经本站转发给所填 API 用于认证，不在本站持久保存或写入仓库。管理入库密码由服务端校验，未填写或校验失败时，抓到的推文只载入编辑器，不加入本机推文库。

    默认抓到的推文直接上卡，随后可在「自由编辑」里继续改。

推文卡片生成器（OPC Tweet Card Studio）

把推文做成可直接发布的图片卡片：写文案或导入你的推文库 → 选背景 → 导出 3:4 / 9:16 竖图、透明 PNG，或 3 秒动效 Live 图素材（MP4）。全部在浏览器本地完成，数据不上传。

🤖 也可以让 AI Agent 直接调用：调好样式后到左下角「交给 AI Agent」复制一段指令，发给 Claude Code / Codex 即可批量出图（参数文档）。

    02

    在线抓取

    贴一条推文链接，直接抓成卡片

    令牌只存在你自己的浏览器里（localStorage），不会上传，也不会写进部署的站点。管理入库密码由服务端校验，密码不对时抓到的推文只进编辑器、不入推文库。

    默认抓到的推文直接上卡，随后可在「自由编辑」里继续改。

    账号信息

    名称
    用户名（不带 @）

    推文库格式：JSON 数组，每条只有 text 必填；date / datetime / topic / sourceUrl / metrics / media 可选。metrics 缺失或全为 0 时，卡片会用随机互动数据填充。导出后替换项目里的 posts.json 再部署，抓到的推文就沉淀进库了。

    04

    用 X API 同步推文

    用你自己的 API Key（BYOK），头像昵称自动填好

    还没有 Key？去 X Developer Portal 创建 ↗　新建 App → Keys and tokens，只复制 Bearer Token；API Key / Secret 用不到。

    用户名（不带 @）
    拉取上限

    Key 只存你的浏览器本地；请求经 tools.box.opc.tools 无状态转发，不记录、不存储。X API 按量计费约 $0.005/条（同步 300 条 ≈ $1.5，需先在 Console 充值）；同一账号再次同步自动增量。

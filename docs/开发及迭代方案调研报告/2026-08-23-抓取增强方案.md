## 3. 三个调研发现

### 3.1 推文库数据格式已经具备，不用改

实测 `posts.json` 836 条：**全部有 `metrics` 和 `datetime`**，`views` 全部 >0，`likes` 748 条 >0，`sourceUrl` 全部有。

「让推文库带上互动数据和发布时间字段」数据侧早就做好了，问题在渲染层——`selectPost()` 每次都调 `rollMetrics()` 用随机值覆盖真实值。本轮改渲染层即可，格式只需新增可选的 `media` 字段。

### 3.2 图片跨域可直接用，无需代理

实测 `pbs.twimg.com` 返回 `access-control-allow-origin`（回显请求 Origin），本地 `127.0.0.1:8798` 与线上 `tcs.opc.tools` 都通过。`<img crossOrigin="anonymous">` 加载后 **canvas 未被污染**，`toDataURL()` 正常。

所以推文库只存图片 URL（不存 dataURL，避免撑爆 localStorage 配额），渲染时直接用 URL + `crossOrigin`。

### 3.3 安全区中心与默认 cardY 精确对应

| mode | 画布高 | 安全区上 | 安全区下 | 可用高度 |
|---|---|---|---|---|
| poster | 720 | 75 | 150 | **495** |
| tall | 960 | 88 | 150 | **722** |

安全区垂直中心比画布中心高 37.5px，**正好等于默认 `cardY = -37`**——说明按安全区约束缩放本就是这套设计的意图，现有的 `stage.clientHeight * 0.92` 只保证在画布内。

## 4. 实施细节

### 4.1 入库门禁

**面板交互**：`importer-save` 点击后自动收起设置区，再点齿轮才展开。

**密码校验放在 Function 侧**，前端不硬编码正确密码：

- Function 读 `env.IMPORT_ADMIN_PASSWORD`，与请求头 `X-Admin-Password` 比对
- 未配置该环境变量时视为放行（本地开发与单人使用行为不变）
- 结果以 `_canSave` 注入响应（Function 从纯透传改为解析后注入这一个字段）

前端据 `_canSave` 决定入库或仅带入编辑框。

> **诚实说明**：入库是纯前端行为，改 JS 就能绕过。这道门禁是流程门槛，不是安全边界。真正的防护要等推文库迁到服务端存储。

**导出推文库 JSON**：账号信息区「导入」旁加「导出」按钮，把 `state.posts` 下载成 `posts.json`——这才是把抓到的好推文真正沉淀进仓库的路径（导出 → 替换项目里的 posts.json → 重新部署）。

### 4.2 真实互动数据

```js
function hasRealMetrics(p) {
  const m = p && p.metrics;
  return !!m && ["likes", "replies", "reposts", "bookmarks", "views"].some((k) => Number(m[k]) > 0);
}
```

`selectPost()`：有真实值就用，否则 `rollMetrics()`。state 加 `metricsIsReal` 标记。「换一组数据」语义变为**强制切换到随机**（有真实数据时也能点，用于美化）。

### 4.3 图片入卡

**数据结构**：post 新增可选 `media: { image, video }`。抓取时取 `thread.tweets[0].images[0]` 与 `videos[0]`——**只取主推文的**，顶层 `media[]` 含整条 thread 的媒体。`video` 只做记录，卡片不播放。

**正文清洗**：抓来的正文末尾带媒体短链（实测 `…可玩性真不错！ https://t.co/G4AY9T5fsy`）。用 `text.replace(/https:\/\/t\.co\/\w+/g, "")` + trim。上游已把普通外链展开成明文，剩下的 t.co 都是媒体链接。

**渲染**：`#tc-body` 之后插 `<img class="tc-media" crossorigin="anonymous">`，X 原生样式。

**fitScale 双基准**：有图片时按安全区可用高度算，纯文字沿用 `* 0.92`——否则所有历史分享链接的出图都会突然变小，是破坏性变更。

**图片加载后必须重算 fitScale**：现有逻辑在 rAF 里读 `card.offsetHeight`，图片没加载完时高度是错的。给图片挂 `onload` 再触发一次测量。

**开关**：右栏样式区加「显示图片」segmented，`state.mediaOn` 默认 true，仅在当前推文有图时显示。

**URL 参数**（三处同步）：`img`（图片 URL，让 embed 也能出带图卡）、`media=off`。

### 4.4 文档同步

`README.md` / `llms.txt` 的推文库格式说明补 `metrics` / `datetime` / `media`，并说明「metrics 缺失时卡片用随机数据填充」。
